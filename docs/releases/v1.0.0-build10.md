# AdaptivePDF 1.0.0 预览版（build 10）

这次更新整理了原生 macOS 阅读界面，同时保留正文和缩略图的图片保色深色模式。

- 翻页、缩放、标注与主题工具分组，颜色选择显示色块；窄窗口保留翻页、主题、侧栏和搜索入口。
- 统一深浅主题下的侧栏与阅读画布，缩略图增加选中描边并按页面比例排列。
- 批注与搜索结果使用更清晰的内容层次，补齐空状态提示。
- 精简底栏，显示当前页码、总页数和缩放比例。
- 更新欢迎页，支持选择或拖入 PDF。

[查看实际应用截图](https://github.com/MrszhuL/AdaptivePDF#界面预览)。Debug 和优化构建各通过 143 项主集成断言；关闭/退出、主题重启、490 页文档回归和缩略图图片保色检查继续执行。

下载 DMG 后将应用拖入 Applications。最低 macOS 15；安装包包含 Intel x86_64 与 Apple 芯片 arm64。Apple 芯片真机尚未实测，不支持 iPadOS。

当前仍是 ad-hoc 签名预览版，尚未经过 Developer ID 签名和 Apple 公证。完整实体鼠标键盘、Preview 互操作和下载隔离环境的 Gatekeeper 验收仍待完成。第三方许可随包提供；项目尚未指定开源许可证。
