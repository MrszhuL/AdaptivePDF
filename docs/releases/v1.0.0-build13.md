# AdaptivePDF 1.0.0 预览版（build 13）

界面围绕 PDF 阅读重新整理：标题与单行工具栏合计 38 点高，主题入口缩为图标，颜色入口缩为圆点。点击圆点即可在原生弹出面板中选择黄色、绿色、蓝色或粉色，细圆环标识当前颜色。底部状态栏缩至 26 点，并显示阅读进度细线。

侧栏采用柔和背景和选中底色，页码、批注卡片与空状态统一字号和间距。浅色、深色及窄窗口均有实际窗口复核。每种构建通过 158 项主集成断言及独立的 15 项界面断言，包括高亮按钮状态、四色面板、改色和撤销/重做。

本版本包含 build 12 的完整独立矢量插图保色修复。保护依据为 PDF 的 Form 对象边界，没有独立封装的矢量插图仍可能变色，详见 README。

需要 macOS 15 或更新版本，提供 Intel 和 Apple 芯片的 Universal 应用；Apple 芯片尚未完成真机验收，当前不支持 iPad。仍采用本地 ad-hoc 签名，未完成 Developer ID 签名与 Apple 公证，完整外部验收状态见 `TESTING.md` 与 `RELEASE.md`。
