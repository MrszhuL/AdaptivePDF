# AdaptivePDF 1.0.0 预览版（build 12）

修复深色模式中插图内部黑字、箭头、灰度矩阵和底色被改变的问题。独立封装的矢量插图现在整图保持原样，包含其中的文字、线条、色块、照片和原有白底；图外正文与页面背景继续变暗。

支持插图的缩放旋转、嵌套内容、透明度、裁切和不同继承颜色。页级图形包装层仍可变暗。该保护基于 PDF 的 Form 对象边界；直接与正文混排且没有独立封装的矢量图仍可能变色，较小的正文 Form 也可能保留原色。

Debug 和优化构建各通过 158 项主集成断言；五处完整矢量插图的最大通道像素差为 0，另有 17 处图片区域和对应缩略图检查。关闭/退出、主题重启和 490 页结构、保存与重开回归继续执行。阅读主题不会写入原 PDF。

本版本为 Universal macOS 应用，需要 macOS 15 或更新版本。Apple 芯片尚未完成真机测试，当前不支持 iPad。安装包仍采用本地 ad-hoc 签名，未完成 Developer ID 签名与 Apple 公证；完整 UI 和 Preview 互操作验收范围见 `TESTING.md` 与 `RELEASE.md`。
