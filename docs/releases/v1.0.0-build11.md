# AdaptivePDF 1.0.0 预览版（build 11）

修复部分 PDF 在选择深色阅读后仍整篇白底的问题。普通透明度现在可以正常显示为深灰背景，图片保持原有颜色和透明度；图片完全透明时不会出现白色块。

嵌套图形遇到复杂混合时，现在只让对应页面保留原色，避免错误传播导致其余页面也无法变暗。深色效果仍仅用于阅读，原始 PDF 不会因此改写。

Debug 和优化构建各通过 149 项主集成断言，17 处图片区域的逐通道平均像素差均为 0；关闭/退出、主题重启、缩略图保色和 490 页文档回归继续执行。

安装包为 Intel 与 Apple 芯片的 Universal macOS 应用，需要 macOS 15 或更新版本。Apple 芯片尚未完成真机测试；当前不支持 iPad。

本版本仍采用本地 ad-hoc 签名，未完成 Developer ID 签名与 Apple 公证。完整 UI 和 Preview 互操作仍有待验收项目，详情见仓库中的 `TESTING.md` 与 `RELEASE.md`。下载后可用同一发布页的 `SHA256SUMS` 校验安装包。
