# AdaptivePDF 1.0.0 预览版（build 14）

连续阅读时，两页之间的大块应用底色缩为细缝：页面上下外边距各为 0.5 点，页间距仅为原来的 1/40。100% 缩放时为 1 点，191% 时约为 1.91 点。浅色和深色阅读都移除了页边阴影，让页面衔接更连贯。

修改只影响阅读器显示布局，PDF 原有纸张边距、文字、图片与批注不作裁切或改写。继续包含紧凑工具栏、四色高亮面板及独立矢量插图保色。

提供 Intel 和 Apple 芯片的 Universal macOS 安装包，需要 macOS 15 或更新版本；Apple 芯片尚未完成真机验收，当前不支持 iPad。仍为本地 ad-hoc 签名的预览版，未完成 Developer ID 签名与 Apple 公证。验证范围与剩余验收项目见 `TESTING.md`、`RELEASE.md` 和发布页的 `release-manifest.json`。
