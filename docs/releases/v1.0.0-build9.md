# AdaptivePDF 1.0.0 预览版（build 9）

修复左侧缩略图在深色阅读下仍显示白色页面的问题。正文与缩略图现在使用同一份保色显示文档，嵌入图片保持原色，主题设置不写入原 PDF。

- 点击缩略图跳页，阅读翻页时同步当前页选择。
- 批注修改和文档替换后刷新预览；快速切换主题时丢弃过期渲染结果。
- 后台串行渲染小尺寸预览，缓存上限 48 张、16 MiB。
- 复杂绘制页与解锁后的加密页继续保留原色。

Debug 和优化配置各通过 143 项主集成断言（含新增 24 项缩略图检查）、10 个关闭/退出场景（60 项断言）、9 种主题/策略重启组合（105 项断言）。完整文档回归共 490 页。缩略图的 9 处图片采样颜色保持一致。

下载 DMG 后将应用拖入 Applications。最低 macOS 15；包含 Intel 与 Apple 芯片原生架构，Apple 芯片真机尚未实测。不支持 iPadOS。

当前为 ad-hoc 签名预览版，尚未经过 Developer ID 签名和 Apple 公证。完整应用窗口、实体鼠标键盘、Preview 交互、下载隔离环境的 Gatekeeper 验收仍待完成。详见 [测试记录](https://github.com/MrszhuL/AdaptivePDF/blob/v1.0.0-build9/TESTING.md)。

附件包含应用 DMG、应用 ZIP、源码 ZIP、SHA256SUMS 和 release-manifest.json。项目尚未指定开源许可证；第三方许可随应用和源码提供。
