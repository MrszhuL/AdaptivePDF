# AdaptivePDF 1.0.0 预览版（build 8）

原生 macOS PDF 阅读器，重点提供页面深色、嵌入图片保色，以及标准高亮、评论和便签。

## 下载与安装

- `AdaptivePDF.dmg`：推荐；打开后将应用拖入 Applications。
- `AdaptivePDF-macOS.zip`：相同应用的 ZIP 压缩包。
- `AdaptivePDF-source.zip`：包含 Xcode 工程、源码、测试和随包 qpdf 依赖。
- `SHA256SUMS`：下载文件的 SHA256 校验值。
- `release-manifest.json`：构建版本、架构、验证摘要和源码文件哈希。

最低系统为 macOS 15。安装包包含 Intel x86_64 与 Apple 芯片 arm64 两种架构；Intel 已运行验证，Apple 芯片真机尚未实测。当前不支持 iPadOS，包括 M 芯片 iPad。

当前是预览版：仅采用本地 ad-hoc 签名，尚未完成 Developer ID 签名、Apple 公证和下载隔离环境的完整安装验收。如首次打开被系统阻止，请在确认来源后参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 包含功能

- 原生 PDF 阅读、文字选择与复制、缩放、导航、异步搜索和多窗口。
- 跟随系统、浅色、深色阅读；默认保留嵌入图片颜色。
- 四色标准高亮、文字评论、页面便签、批注侧栏与撤销/重做。
- 保真批注保存，校验原始页面、字体和图片资源；主题显示不改写原 PDF。
- 加密 PDF 解锁阅读与只读保护，基础 AcroForm 字段值保存。

## 验证与边界

Debug 和优化配置各通过 119 项主集成断言、10 个关闭/退出场景（60 项断言）、9 种主题/策略重启组合（105 项断言）；完整回归集共 490 页。

图片保色的独立结构及渲染检查覆盖 RGB、灰度、CMYK、ICC、透明遮罩、内联图片、嵌套 Form、裁切和旋转，9 个采样区域的逐通道平均像素差均为 0。

扫描图片本身保持原色，整页扫描件可能仍是白底。中性灰色矢量线条随页面调整；复杂混合和特殊绘制页明确保留原色。完整硬件交互、实际窗口像素、Preview 交互及 Apple 芯片真机仍待验收，详细范围见 [测试记录](https://github.com/MrszhuL/AdaptivePDF/blob/v1.0.0-build8/TESTING.md)。

第三方许可随应用与源码提供；项目本身尚未指定开源许可证。
