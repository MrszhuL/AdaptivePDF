# AdaptivePDF 1.0.0 预览版（build 15）

修复印刷论文中的专色色彩空间触发整页原色回退、导致深色阅读仍显示白底的问题。颜色解析交给 macOS Core Graphics，适用于 Separation、DeviceN、Indexed、Lab、ICC 与校准色彩空间；按实际颜色调整中性灰阶，保留图片和独立插图原色，不依赖论文标题、文件名或专色名称。

补齐源色彩空间与显示颜色的状态隔离，避免连续颜色操作、描边或图形状态恢复时串色；不可见墨色继续不可见。新增九页生成样本验证四类专色函数、正文、线条、彩色绘制、完整插图、位图及缩略图。Debug 和优化配置各通过 188 项主断言、15 项工具栏检查，以及关闭/退出、主题重启和 490 页文档回归。

继续保留紧凑工具栏和连续页间细缝。修改只影响阅读器显示，原 PDF 和保存路径保持原内容。整页扫描图、复杂混合、Pattern 与未独立封装的矢量绘制仍有既有保色边界，具体见 README 和 TESTING。

提供 Universal macOS 安装包，需要 macOS 15 或更新版本；Apple 芯片尚未完成真机验收，不支持 iPad。仍为本地 ad-hoc 签名的预览版，未完成 Developer ID 签名和 Apple 公证。
